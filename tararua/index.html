how it works

Send the location, approximate net area, build type and timing. We’ll confirm the site suits a fall arrest net system and line the work up with your programme.

  1. 01

    plan

    Check the work area, access, anchor points, fall distance, clearance and timing.

  2. 02

    install

    Inspect the nets and complete the FASET-certified installation.

  3. 03

    hire

    Leave the nets in place for the agreed build period.

  4. 04

    handover

    Provide installation checks and details for the site file.

  5. 05

    remove

    Plan removal once the protected work is finished.
